# Security

Kūhaku lets Claude act on the computer, so faults that let something cross a line matter most:
a way around the safety net (`kuhaku-guard.py`), text in a page or email that gets Claude to act
on its own, a secret leaving the computer, or a privilege that is wider than it should be.

Please report these **privately**, through
[a security advisory](https://github.com/rudolfkrcmar/kuhaku-linux/security/advisories/new),
not as a public issue. You will hear back within a week. Fixes go into the next release, and the
changelog thanks you unless you would rather not be named.

Only the latest release is supported.
